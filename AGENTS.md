# AGENTS.md

Instructions for AI coding agents working in this repo.

1. Read `CLAUDE.md` first: what the project is, the stack and the rules that protect correctness. They apply to every agent, not only Claude.
2. Read `CONTRIBUTING.md` before any git command. The short version: **never commit or push to `main`.** Work on a branch, push the branch, open a pull request with `gh pr create --base main`, and let Chime (`ChimeXXD`) review and merge it. Never merge your own pull request.
3. Then `docs/HANDOFF.md` for where the work stands.
