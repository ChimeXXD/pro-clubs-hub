| [PRO11](https://www.pro11.net/) | Archetype pages, build guides, sources box | Sources and update date at the top of a build; per-archetype pages | Blog layout; long text before the build |
| [FC Tools Hub](https://fctoolshub.com/en/guides/fc27/face-creator-guide) | Face creator guide | Tab-by-tab structure (Skin, Head, Face, Hair) | Ads gate mid-guide |
| [Dexerto builds](https://www.dexerto.com/wikis/ea-fc-27/best-clubs-builds-for-all-positions/) | Build tables | A compact table per position | No method, no date, no credit |
